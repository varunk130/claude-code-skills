# Examples

Worked examples that show exactly what a skill produces. Each one starts with the prompt a user typed in Claude Code, then shows abridged output that follows the skill's phases, tables, and formulas step by step, with numbers you can check by hand. Companies, competitors, and figures are fictional, and the Artificial Intelligence (AI) search measurements are illustrative.
